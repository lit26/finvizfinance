Configuration & Utilities

finvizfinance.util

Global settings that affect every network request the library makes, plus the low-level scraping helpers the rest of the package is built on.

Global state set_proxy and set_timeout mutate module-level globals and a shared requests.Session. Set them once, early — they apply to all subsequent calls across every module.

set_proxy

functionset_proxy(proxies)

Route all FinViz requests through an HTTP/HTTPS proxy. The dictionary is passed straight to requests as its proxies argument.

ParameterTypeDescription
proxiesdictrequiredA requests-style proxy map, e.g. {'http': 'http://127.0.0.1:8080', 'https': 'http://127.0.0.1:8080'}.
Returns   None.
from finvizfinance.util import set_proxy

set_proxy({'http': 'http://127.0.0.1:8080'})

set_timeout

functionset_timeout(timeout)

Override the per-request timeout (default 10 seconds).

ParameterTypeDescription
timeoutint | floatrequiredSeconds before a request is abandoned with a requests.exceptions.Timeout.
Returns   None.
from finvizfinance.util import set_timeout
set_timeout(30)

Internal helpers

These power the higher-level classes. You normally won't call them directly, but they're documented here for completeness and for anyone extending the library.

functionweb_scrap(url, params=None)

GET a URL through the shared session (honouring proxy & timeout) and parse the HTML.

Returns   bs4.BeautifulSoup. Raises requests HTTPError/Timeout on failure.
functionimage_scrap(url, ticker, out_dir)

Download an image URL and save it as <ticker>.jpg in out_dir.

Returns   None.
functionscrap_function(url)

Parse a FinViz "groups" performance table (used by Forex/Crypto).

Returns   pandas.DataFrame.
functionimage_scrap_function(url, chart, timeframe, urlonly)

Resolve a Forex/Crypto chart image URL for the given timeframe and optionally download it.

Returns   str — the chart URL.
functionnumber_covert(num)

Convert a FinViz numeric string to a float: strips commas, expands K/M/B suffixes, turns a trailing % into a fraction, and maps empty / '-' to None.

Returns   float or None.
functionformat_datetime(date_str)

Parse FinViz date strings (including the "Today HH:MMam/pm" form) into a datetime.

Returns   datetime.datetime.
functionprogress_bar(page, total)

Render the text progress bar shown while the screener pages through results.

Returns   None.
