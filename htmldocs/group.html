Group

finvizfinance.group.*

Aggregated metrics for whole sectors, industries, countries and market-cap buckets — the same numbers as the screener, but rolled up by group instead of per ticker.

The group pattern

Pick a view class, then call screener_view() with the grouping and sort order you want. Unlike the screener, groups need no filters and return everything in a single request.

from finvizfinance.group.overview import Overview

foverview = Overview()
df = foverview.screener_view(group='Sector', order='Name')
df.head()

View classes

Import each from its submodule, e.g. from finvizfinance.group.performance import Performance. All take no constructor arguments.

screener_view

methodscreener_view(group='Sector', order='Name', columns=None)

Available on Overview, Valuation and Performance.

ParameterTypeDescription
groupstr= 'Sector'How to bucket the market, e.g. 'Sector', 'Industry', 'Capitalization', or an industry-within-sector option. Invalid values raise ValueError. Full list: Group options.
orderstr= 'Name'Sort field, e.g. 'Name', 'Market Capitalization', 'Performance (Week)'. Invalid values raise ValueError. Full list: Group orders.
columnslist= NoneIgnored for standard views; used only by Custom.
Returns   pandas.DataFrame, one row per group, numeric columns converted to float.

class Custom

methodscreener_view(group='Sector', order='Name', columns=[0,1,2,3,10,22,24,25,26])

Like the standard group view, but you select the columns by index.

ParameterTypeDescription
groupstr= 'Sector'See Group options.
orderstr= 'Name'See Group orders.
columnslist[int]= [0,1,2,3,10,22,24,25,26]Column indices to include.
Returns   pandas.DataFrame with your chosen columns.
from finvizfinance.group.custom import Custom
df = Custom().screener_view(group='Industry', columns=[0, 1, 2, 3, 10])

class Spectrum

methodscreener_view(group='Sector', order='Name', out_dir='')

Downloads the FinViz "spectrum" image — a colour map of relative performance across the group — and saves it as <group>.jpg.

ParameterTypeDescription
groupstr= 'Sector'See Group options.
orderstr= 'Name'See Group orders.
out_dirstr= ''Destination directory for the image.
Returns   None — the image is written to disk.
