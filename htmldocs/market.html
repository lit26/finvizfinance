Market Data

Market-wide feeds that are not tied to a single ticker: financial news, insider-trading activity, the economic calendar, and earnings-date partitioning.

class News

finvizfinance.news

classNews()

Loads the FinViz news page on construction.

methodget_news()

Parses the page into two tables — mainstream news and blogs.

Returns   dict with keys 'news' and 'blogs', each a pandas.DataFrame with columns Date, Title, Source, Link.
from finvizfinance.news import News

all_news = News().get_news()
all_news['news'].head()
all_news['blogs'].head()

class Insider

finvizfinance.insider

classInsider(option='latest')

Loads a slice of FinViz's market-wide insider-trading page on construction. The option chooses which slice.

ParameterTypeDescription
optionstr= 'latest'One of the values below, or a numeric insider id (as a string) to fetch one insider's history.

Valid option values:

latestlatest buyslatest sales top weektop week buystop week sales top owner tradetop owner buystop owner sales <insider_id>
methodget_insider()

Returns the insider-trading table for the configured option.

Returns   pandas.DataFrame with columns such as Ticker, Owner, Relationship, Date, Transaction, Cost, #Shares, Value ($), #Shares Total, SEC Form 4, plus a SEC Form 4 Link URL column. Numeric columns are converted to float.
from finvizfinance.insider import Insider

finsider = Insider(option='top owner trade')
df = finsider.get_insider()

class Calendar

finvizfinance.calendar

classCalendar()

Wrapper around the FinViz economic-calendar page.

methodcalendar()

Fetches the week's scheduled U.S. economic releases.

Returns   pandas.DataFrame with columns Datetime, Release, Impact, For, Actual, Expected, Prior.
from finvizfinance.calendar import Calendar
df = Calendar().calendar()

class Earnings

finvizfinance.earnings

classEarnings(period='This Week')

Pulls every stock reporting earnings in a chosen period and groups them by earnings date. On construction it runs a Financial screen filtered to the period.

ParameterTypeDescription
periodstr= 'This Week'One of 'This Week', 'Next Week', 'Previous Week', 'This Month'. Other values raise ValueError.

partition_days

methodpartition_days(mode='financial')

Splits the period's stocks into a separate table per earnings date, fetched in the chosen view.

ParameterTypeDescription
modestr= 'financial'Which screener view to use: 'financial', 'overview', 'valuation', 'ownership', 'performance', 'technical'. Other values raise ValueError.
Returns   dict mapping each earnings date (str) to a pandas.DataFrame of the stocks reporting that day.

output_excel

methodoutput_excel(output_file='earning_days.xlsx')

Writes the partitioned tables to a single Excel workbook, one sheet per date. Requires xlsxwriter. Call partition_days() first.

Returns   None.

output_csv

methodoutput_csv(output_dir='earning_days')

Writes the partitioned tables to one CSV file per date inside output_dir (created if missing). Call partition_days() first.

Returns   None.
from finvizfinance.earnings import Earnings

fearn = Earnings(period='This Week')
days = fearn.partition_days(mode='overview')   # {'May 06/a': DataFrame, ...}
fearn.output_csv('my_earnings')
