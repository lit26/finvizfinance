finvizfinance

A Python library that downloads stock, forex, crypto, and futures data from the FinViz website and returns it as tidy pandas DataFrames.

finvizfinance scrapes FinViz's public web pages and exposes them through a small, consistent set of Python classes. It is useful for quantitative research, screening universes of stocks against fundamental and technical filters, pulling insider trades and news, and downloading charts.

What this library returns Most methods return a pandas.DataFrame; a few return a dict, a list, or download an image to disk. Every method documents its exact return type below.

Installation

finvizfinance supports Python 3.9+ and depends on pandas, requests, beautifulsoup4, and lxml.

# From PyPI
pip install finvizfinance

# From source
git clone https://github.com/lit26/finvizfinance.git

Quick start

from finvizfinance.quote import finvizfinance

stock = finvizfinance('AAPL')
fundament = stock.ticker_fundament()   # dict of ~70 fundamentals
news_df    = stock.ticker_news()       # pandas DataFrame

from finvizfinance.screener.overview import Overview

foverview = Overview()
foverview.set_filter(filters_dict={'Index': 'S&P 500', 'Sector': 'Technology'})
df = foverview.screener_view()         # DataFrame of matching tickers

Library map

Pick the module that matches the data you need.

Stock Quote

Fundamentals, description, peers, ETF holders, analyst ratings, news, insider trades, signals and financial statements for a single ticker.

Screener

Filter the entire stock universe and pull Overview, Valuation, Financial, Ownership, Performance, Technical, Custom or Ticker-only tables.

Group

Aggregated metrics by Sector, Industry, Country or Market-Cap, plus relative-performance spectrum images.

Market Data

Market-wide News & blogs, Insider trading activity, the economic Calendar, and Earnings-date partitioning.

Forex · Crypto · Future

Performance tables and downloadable charts for foreign exchange, cryptocurrencies and futures.

A note on web scraping finvizfinance reads FinViz's live HTML. If FinViz changes its page layout or rate-limits your IP, calls may raise requests exceptions or return unexpected shapes. Be considerate with request volume — the screener already sleeps between pages (see the sleep_sec argument) — and consider a proxy for heavy use. Respect FinViz's terms of service.
