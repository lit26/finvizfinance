Stock Quote

finvizfinance.quote

Everything FinViz publishes about a single ticker: fundamentals, profile, peers, ETF holders, analyst ratings, news, insider trades, technical signals and financial statements.

On this page
  • class finvizfinance — the main per-ticker object
  • class Quote — real-time last price
  • class Statements — income / balance / cash-flow statements

class finvizfinance

classfinvizfinance(ticker, verbose=0)

Loads the FinViz quote page for one ticker once, on construction, and caches the parsed HTML. Every ticker_* method reads from that cached page (only ticker_charts, ticker_signal and the statements helper make additional network calls).

ParameterTypeDescription
tickerstrrequiredTicker symbol, e.g. 'AAPL'. Case-insensitive.
verboseint= 0Set to 1 to print "Ticker exists." during construction.

If the symbol is not found on FinViz, the constructor prints "Ticker not found." and sets the internal flag attribute to True.

from finvizfinance.quote import finvizfinance
stock = finvizfinance('tsla')

ticker_fundament

methodticker_fundament(raw=True, output_format='dict')

Returns the full fundamentals snapshot (the FinViz "snapshot" table) — roughly 70 key/value metrics such as P/E, EPS, Market Cap, margins, performance and 52-week range, plus Company, Sector, Industry, Country and Exchange.

ParameterTypeDescription
rawbool= TrueWhen True, values are returned as the original strings (e.g. '302.10B', '13.63%'). When False, numeric values are converted to float (percentages become fractions, suffixes K/M/B are expanded, '-' becomes None) and Optionable/Shortable become booleans.
output_formatstr= 'dict''dict' returns a plain dictionary; 'series' returns a single-column pandas.DataFrame indexed by metric name. Any other value raises ValueError.
Returns   dict (default) or pandas.DataFrame — see output_format.

Note: composite cells are split into separate keys — 52W Range → 52W Range From/52W Range To, and Volatility → Volatility W/Volatility M.

f = stock.ticker_fundament()
# {'Company': 'Tesla, Inc.', 'Sector': 'Consumer Cyclical',
#  'P/E': '849.57', 'Market Cap': '302.10B', ...}

f_numeric = stock.ticker_fundament(raw=False)
# {'P/E': 849.57, 'Market Cap': 302100000000.0, 'Optionable': True, ...}

Peer (comparable) ticker symbols that FinViz links from the quote page.

ticker_etf_holders

methodticker_etf_holders()

ETFs that hold the given ticker ("Held by" on FinViz).

Returns   list[str] — ETF symbols, or an empty list if none are found.
stock.ticker_etf_holders()

ticker_outer_ratings

methodticker_outer_ratings()

Analyst rating changes (upgrades, downgrades, initiations, price targets).

Returns   pandas.DataFrame with columns Date, Status, Outer (the analyst firm), Rating, Price — or None if the ticker has no ratings table.

ticker_news

methodticker_news()

Recent news headlines linked to the ticker.

Returns   pandas.DataFrame with columns Date (parsed datetime), Title, Link, Source — or None if there is no news table.

ticker_inside_trader

methodticker_inside_trader()

Insider transactions reported for this ticker.

Returns   pandas.DataFrame including Insider Trading, Relationship, Date, Transaction, Cost, #Shares, Value ($), #Shares Total, SEC Form 4 Link and Insider_id — or None if no insider table exists. Numeric columns (Cost, #Shares, Value, #Shares Total) are converted to float.

ticker_charts

methodticker_charts(timeframe='daily', charttype='advanced', out_dir='', urlonly=False)

Builds the FinViz chart URL for the ticker and, unless urlonly=True, downloads the chart image to disk as <ticker>.jpg.

ParameterTypeDescription
timeframestr= 'daily'One of 'daily', 'weekly', 'monthly'. Other values raise ValueError.
charttypestr= 'advanced'One of 'candle', 'line', 'advanced'. (Technical overlays from 'advanced' apply on the daily timeframe only.) Other values raise ValueError.
out_dirstr= ''Directory to save the image into. Empty string saves in the current working directory.
urlonlybool= FalseWhen True, skip downloading and just return the URL.
Returns   str — the chart image URL.
url = stock.ticker_charts(timeframe='weekly', charttype='candle', urlonly=True)

ticker_signal

methodticker_signal()

Checks the ticker against every FinViz technical/screener signal and returns the ones it currently matches (e.g. 'Top Gainers', 'Channel Up', 'Double Bottom').

Returns   list[str] — matching signal names. See the full set in Reference Data → Signals.
Cost This runs one screener request per signal (33 in total), so it is comparatively slow.

ticker_full_info

methodticker_full_info()

Convenience aggregator: runs ticker_fundament(), ticker_outer_ratings(), ticker_news() and ticker_inside_trader() and returns them together.

Returns   dict with keys fundament, ratings_outer, news, inside trader.

classQuote()

ParameterTypeDescription

from finvizfinance.quote import Quote

class Statements

classStatements()

Downloads financial statements from FinViz's statement API.

methodget_statements(ticker, statement='I', timeframe='A')
ParameterTypeDescription
tickerstrrequiredTicker symbol.
statementstr= 'I''I' = Income Statement, 'B' = Balance Sheet, 'C' = Cash Flow.
timeframestr= 'A''A' = Annual, 'Q' = Quarterly.
Returns   pandas.DataFrame — line items as rows, reporting periods as columns. Raises an exception on HTTP errors.
from finvizfinance.quote import Statements
income = Statements().get_statements('AAPL', statement='I', timeframe='Q')
