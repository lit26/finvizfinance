Forex · Crypto · Future

Performance tables and downloadable charts for the non-equity markets FinViz tracks.

Chart timeframes The chart() methods of Forex and Crypto accept these timeframe codes: '5M' (5-minute), 'H' (hourly), 'D' (daily), 'W' (weekly), 'M' (monthly). Any other value raises ValueError.

class Forex

finvizfinance.forex

classForex()

Foreign-exchange performance and charts.

methodperformance(change='percent')

Performance table across all currency pairs.

ParameterTypeDescription
changestr= 'percent''percent' for percentage change, 'PIPS' for change in pips. Other values raise ValueError.
Returns   pandas.DataFrame — performance per pair across multiple timeframes.
methodchart(forex, timeframe='D', urlonly=False)

Builds (and optionally downloads) the chart image for one currency pair.

ParameterTypeDescription
forexstrrequiredPair name, e.g. 'EURUSD'.
timeframestr= 'D'One of 5M, H, D, W, M.
urlonlybool= FalseWhen True, return the URL without downloading.
Returns   str — the chart image URL (the image is also saved to disk unless urlonly=True).
from finvizfinance.forex import Forex

fforex = Forex()
df  = fforex.performance()
url = fforex.chart('EURUSD', timeframe='D', urlonly=True)
