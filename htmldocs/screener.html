Screener

finvizfinance.screener.*

Filter the entire stock universe by fundamental, descriptive and technical criteria, then pull the matching tickers as a DataFrame in one of several "views".

The screener pattern

Every screener follows the same three steps. Choose a view class for the columns you want, apply filters, then call screener_view() to download the table.

from finvizfinance.screener.overview import Overview

foverview = Overview()                                  # 1. pick a view
foverview.set_filter(filters_dict={'Index': 'S&P 500',    # 2. apply filters
                                   'Sector': 'Basic Materials'})
df = foverview.screener_view()                          # 3. download → DataFrame
df.head()

All view classes share the same methods (set_filter, screener_view, compare, reset) inherited from an internal Base class. They differ only in which set of columns FinViz returns.

View classes

Import each from its own submodule, e.g. from finvizfinance.screener.valuation import Valuation. All are constructed with no arguments.

ClassSubmoduleColumns it returns

classValuationscreener.valuationValuation multiples: P/E, Fwd P/E, PEG, P/S, P/B, P/C, P/FCF, EPS & sales growth.
classFinancialscreener.financialMargins, ROA/ROE/ROI, dividend, debt ratios, earnings date.
classOwnershipscreener.ownershipInsider & institutional ownership/transactions, float short, shares outstanding.
classPerformancescreener.performanceReturns over week→year, volatility, average volume, relative volume, beta.
classTechnicalscreener.technicalBeta, ATR, SMAs, 52-week range position, RSI, gap, change.

classTickerscreener.tickerTicker symbols only, as a Python list — see Ticker.

set_filter

methodset_filter(signal='', filters_dict={}, ticker='')

Configures the screen. Call it before screener_view(). Calling it again adds to the existing configuration; use reset() to clear everything.

ParameterTypeDescription
signalstr= ''A single trading signal, e.g. 'Top Gainers'. Invalid values raise ValueError. Full list: Signals.
filters_dictdict= {}Map of filter name → option, e.g. {'Sector': 'Technology', 'P/E': 'Under 20'}. Both the key and the value are validated against FinViz's allowed sets; an invalid key or option raises ValueError. Full lists: Filters & options.
tickerstr= ''Restrict the screen to a comma-separated set of tickers.
Returns   None (mutates the screener in place).
Discover valid filters & options programmatically Use get_filters(), get_filter_options(name) and get_signal() instead of hard-coding strings.

screener_view

methodscreener_view(order='Ticker', limit=100000, select_page=None, verbose=1, ascend=True, columns=None, sleep_sec=1)

Downloads the filtered table, paging through FinViz results (20 rows per page) until limit is reached or there are no more pages.

ParameterTypeDescription
orderstr= 'Ticker'Sort field. Invalid values raise ValueError. Full list: Orders.
limitint= 100000Maximum number of rows to return (effectively "all").
select_pageint= NoneFetch only this single results page (1-indexed). When set, limit is ignored (a warning is emitted) and None is returned if the page is beyond the available range.
verboseint= 11 prints a progress bar while paging; 0 is silent.
ascendbool= TrueSort ascending (True) or descending (False).
columnslist= NoneIgnored for the standard views; used only by Custom.
sleep_secint= 1Seconds to sleep between page requests, to avoid hammering FinViz.
Returns   pandas.DataFrame of matching rows, or None when no ticker matches the filters. Numeric columns are converted to float.

After a full (non-paged) run the screener auto-calls reset(), clearing your filters.

df = foverview.screener_view(order='Market Cap.', ascend=False, limit=50)

compare

methodcompare(ticker, compare_list, order='ticker', verbose=1)

Convenience method: looks up one ticker's Sector / Industry / Country, then screens for all other tickers that share those properties.

ParameterTypeDescription
tickerstrrequiredThe reference ticker to compare against.
compare_listlistrequiredAny combination of 'Sector', 'Industry', 'Country'. Other values raise ValueError.
orderstr= 'ticker'Sort field (see Orders).
verboseint= 1Progress bar toggle.
Returns   pandas.DataFrame in the calling view's columns.
from finvizfinance.screener.overview import Overview
Overview().compare('AAPL', ['Sector', 'Industry'])

reset

methodreset()

Clears all configured filters/signal/ticker, returning the screener to its initial state.

Returns   None.

class Custom — choose your own columns

classCustom()

Like the other views, but you pick exactly which columns to return by their FinViz index.

methodscreener_view(order='Ticker', limit=-1, select_page=None, verbose=1, ascend=True, columns=[0,1,2,3,4,5,6,7,65,66,67], sleep_sec=1)

Same behaviour as the base screener_view, plus the columns argument.

ParameterTypeDescription
columnslist[int]= [0,1,2,3,4,5,6,7,65,66,67]Column indices to include. Index 0 (No.) is always forced to the front. See the full index→name map in Reference Data → Custom columns.
Returns   pandas.DataFrame with your chosen columns.
from finvizfinance.screener.custom import Custom
fcustom = Custom()
fcustom.set_filter(filters_dict={'Sector': 'Technology'})
df = fcustom.screener_view(columns=[0, 1, 2, 3, 6, 7, 65, 67])

class Ticker — symbols only

classTicker()

Returns just the list of ticker symbols that match the filters — fast, because FinViz packs 1,000 tickers per page.

methodscreener_view(order='Ticker', limit=-1, verbose=1, ascend=True, sleep_sec=1)
ParameterTypeDescription
orderstr= 'Ticker'Sort field (see Orders).
limitint= -1Max number of tickers; -1 means all.
verboseint= 1Progress bar toggle.
ascendbool= TrueSort direction.
sleep_secint= 1Sleep between page requests.
Returns   list[str] of tickers, or None if none match.
from finvizfinance.screener.ticker import Ticker
fticker = Ticker()
fticker.set_filter(signal='Top Gainers')
tickers = fticker.screener_view()   # ['NVDA', 'AMD', ...]
